E-postsignatur

Velg variant, trykk «Kopier signatur» og lim inn i signaturfeltet i e-postprogrammet. Bildene hentes fra mobulamusic.no, og alle lenker er klikkbare.

Gmail

  1. Trykk «Kopier signatur» over.
  2. Gmail → tannhjulet → Se alle innstillinger → Generelt → Signatur → Opprett ny.
  3. Lim inn med ⌘V, rull ned og trykk Lagre endringer.

Apple Mail

  1. Mail → Innstillinger → Signaturer → velg kontoen → +.
  2. Fjern haken for «Bruk alltid standardfonten for meldinger».
  3. Lim inn med ⌘V.

Outlook

  1. Innstillinger → E-post → Signaturer → ny signatur → lim inn med ⌘V → Lagre.
